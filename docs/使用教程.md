# 收到压缩包后，怎样使用纸间 PDF

## 1. 下载软件

请在 Windows 电脑上打开 [下载页面](https://github.com/zhangyuankun01/paperdesk/releases/latest)，在 Assets 中下载 `PaperDesk-2.1.0-windows-x64.zip`，保存到桌面或下载文件夹。

如果你已经从别人那里收到了这个压缩包，直接保存到电脑即可。

## 2. 完整解压

右键点击压缩包，选择“全部解压”或“解压到……”，等待完成。先解压，再运行软件。

## 3. 打开软件

打开解压后的 `PaperDesk-2.1.0` 文件夹，双击 `PaperDesk.exe`。如果电脑隐藏了文件扩展名，名称可能只显示为 `PaperDesk`。

程序旁边的 `_internal` 文件夹也是软件的一部分，请完整保留。软件不需要安装 Python，也不需要登录账号。

## 4. 添加图片

点击“添加图片”，选择图片，再点击“打开”。按住 Ctrl 键可以一次选中多张。也可以把图片拖到软件中间的空白区域。

iPhone 的 HEIC / HEIF 照片可以直接添加，不用先转成 JPG。其他支持格式包括 JPG / JFIF、PNG、WebP、BMP、GIF、TIFF、AVIF、JPEG 2000 等。文件没有显示时，可把选择窗口右下角的文件类型切换到“所有文件”。

## 5. 调整顺序和方向

图片左上角的编号就是 PDF 的页码。拖动卡片调整顺序，或选中图片后点击“前移”“后移”。方向不对时点击“旋转 90°”，操作错了可点击“撤销”。

## 6. 命名并保存 PDF

在右侧填写 PDF 文件名，例如“申请材料.pdf”。日常使用保留“跟随图片尺寸”即可，打印时可选择 A4。

点击“生成 PDF”，选择保存位置，再点击“保存”。看到“PDF 已生成”后，可以点击“打开 PDF”检查结果，或点击“打开所在文件夹”找到文件。

## 下次使用

保留整个解压文件夹，下次双击其中的 `PaperDesk.exe` 即可。整理列表中的“移除”和“清空”会保留电脑上的原图。
